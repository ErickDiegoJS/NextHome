# 🏠 NextHome

Projeto acadêmico **P1** desenvolvido para a disciplina de **Programação para Web**, do curso de Análise e Desenvolvimento de Sistemas da **Fatec**.

O NextHome é uma aplicação web voltada para a área imobiliária, estruturada em duas camadas principais: um back-end em **Java com Spring** e um front-end em **Angular**, que se comunicam entre si por meio de uma API REST.

## 📌 Sobre o nome "NextHome"

O nome do projeto remete à ideia de conectar pessoas à sua **próxima casa**, sugerindo funcionalidades como cadastro, listagem e busca de imóveis — proposta central da aplicação desenvolvida para esta atividade da disciplina.
